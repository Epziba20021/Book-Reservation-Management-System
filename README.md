# Book Reservation Management System

A web application for managing book reservations using HTML, CSS, JavaScript, PHP, and MySQL.

### Features

* Reserve books
* Validate user details
* View and delete reservations
* Sort reservations by name and pickup date

### How to Run

1. Place the project in Laragon's `www` folder.
2. Start Apache and MySQL.
3. Open `http://localhost/Book-Reservation-Management-System/` in your browser.
